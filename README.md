# 📊 Diseño de Datos y Algoritmos (DDYA)

![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat-square&logo=python)
![Status](https://img.shields.io/badge/Status-En%20Desarrollo-green?style=flat-square)

Repositorio dedicado a las prácticas, talleres y avances semanales de la asignatura **Diseño de Datos y Algoritmos**. El objetivo principal es implementar estructuras de datos, analizar la complejidad algorítmica y resolver problemas computacionales en Python.

---

## 📁 Estructura del Repositorio

El código está organizado por entregas semanales y módulos de desarrollo:

```text
DDYA/
├── semana 2/           # Ejercicios y estructuras de la Semana 2
├── semana 3/           # Algoritmos y resolución de problemas de la Semana 3
├── semana 4/           # Contenido y talleres de la Semana 4
└── dev-pr-dynamic/     # Módulo dinámico / Desarrollo en progreso
```
